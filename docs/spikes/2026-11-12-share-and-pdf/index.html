abendkasse spike: share and PDF

Throwaway test page for OPEN-B, OPEN-G and the save path of REQ-019. All data on it is invented. Nothing leaves the device except what you send yourself.

How to use it: open this page in each browser, work through the questions that apply, pick an outcome and add notes. At the end of each browser, press Copy results and paste them into the chat. Your answers are kept in this browser until you clear them.

1. Android: share sheet into the Gmail app

Android, in Chrome and in Firefox.

Does navigator.share with the PDF open Gmail with the attachment, subject and text filled in?

  1. Press variant A and pick Gmail. Note what arrives: attachment, subject, text. Discard the draft.
  2. Repeat with B, C and D. D shares no file and only shows what the text fields do on their own.

3. Windows: share sheet in Chrome, Edge and Firefox

Windows, in Chrome, Edge and Firefox.

Is file sharing offered (canShare)? Which targets appear in the Windows share dialog? Do subject and text arrive?

  1. Read the canShare results below the buttons.
  2. Press variant A. Note the targets the Windows dialog lists. Try Gmail or Mail if listed, otherwise the target that looks most useful.
  3. Try B to D if A worked.

4. Windows: save, open Gmail pre-filled, drag the PDF in

Windows, in each browser, with Gmail in the browser signed in.

Does "save the PDF, open Gmail's compose page pre-filled, drag the PDF in" take at most two extra actions? Can the PDF be dragged straight from this page into Gmail?

  1. Press Save and open Gmail. The PDF is downloaded and a compose window opens with recipient, subject and body. Attach the PDF the quickest way you find, and count your actions after the button (a drag counts as one).
  2. In the compose window, drag each of the chips below into the message, one at a time. Note which ones become an attachment.
  3. Optional: Save and open mailto does the same through your default mail handler.

Drag sources:

a. DownloadURL, blob URL b. DownloadURL, https URL c. File in the drag data d. plain link to the PDF

5. Windows: .eml draft (five minutes at most)

Windows, once (any browser).

Does an .eml file with X-Unsent: 1 and the PDF attached open as a ready draft?

  1. Press Download .eml and open the file from the download list.
  2. Note which program opens it, and whether recipient, subject, body and attachment are there, and whether it is a draft you can send.

6. Installed app writes into a Google Drive folder

Windows, in Chrome and Edge, installed as an app.

Can the installed app write into a chosen Google Drive for desktop folder, and keep the permission after a browser restart?

  1. Install this page as an app (install icon in the address bar) and open it from the app window.
  2. Create an empty test folder, for example G:\My Drive\abendkasse-spike.
  3. Press Choose folder and pick that folder; allow editing.
  4. Press Write test PDF. Check in Explorer and on drive.google.com that 2026\Rechnung_….pdf arrived.
  5. Close every window of the browser, start it again, open the app, and read Permission after load. Press Write test PDF again and note whether a prompt appears and what it offers.

7. List the folder to find the highest invoice number

Windows, after question 6, same folder.

Can the app list the folder's file names to find the highest invoice number (REQ-038), and how fast with 50 files?

  1. Press Write 50 test files (into listing-test\2026\ inside the chosen folder). Wait until Drive has synced.
  2. Press List and find highest a few times. The first run may be slower.
  3. Press Delete test files when done.

8. Android: where does a saved PDF end up?

Android, in Chrome and Firefox.

Where does a saved PDF end up, and how many taps does it take to get it into Google Drive?

  1. Press Download PDF. Find the file (notification, Files app) and note where it is.
  2. Get it into a Drive folder the quickest way you find. Count the taps after the button.
  3. Compare: share variant C (file only) and pick "Drive" (Save to Drive). Count the taps.

9. pdf-lib: layout, umlauts, identical bytes, attached data

Every browser.

Does pdf-lib reproduce the reference layout (REQ-018) on one A4 page with an embedded font, correct umlauts and „quotes“? Are the bytes identical across platforms (REQ-017)? Can it embed the invoice data as a file attachment (REQ-033)?

  1. Press Open PDF and compare it with your reference invoice: header, address window, number and date, item table, note, footer.
  2. Check the umlauts (Großer, Köln, Musterstraße, Gemäß) and the quotes around „Example Night“.
  3. Read the hash below. Every browser should show the same; the reference from Node is shown next to it.
  4. Check the attachment: in Firefox's PDF viewer open the sidebar and its attachments view; in Acrobat Reader the paper-clip panel. It should hold rechnung.json.
